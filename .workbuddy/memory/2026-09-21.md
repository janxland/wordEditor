# 2026-09-21

## wordEditor 新增 `apa7` 模板：APA 7th edition 英文论文/评述导出

**背景**：用户拿两张手机截图（一个 International Finance 课程的 Article Review 作业要求），
要求"以最刁钻的命题完成、AIGC=0、先写 MD 再用 wordEditor MCP 转成所需版式的 docx"。
作业硬性要求：APA 7、正文 500–700 词（不含封面与参考文献页）、双倍行距、
Calibri/Arial/TNR 11pt、1 英寸页边距、页码、封面页 + 参考文献页。

**新增资产**

- `templates/apa7/reference.docx` + `build_reference.py`：版式全部固化在此
  （Letter 12240×15840、四边 1440 twips、Calibri 22 half-pt、line 480、
  页脚居中 PAGE 域、References 悬挂 720/left 720、Heading1 居中加粗无编号）。
- `templates/apa7/apa7-style.lua`：HTML→DOCX 阶段过滤器。约定
  `<div class="pagebreak">` → 分页符，`<div class="cs-XXX">` → 段样式 XXX。
- `templates/apa7/styles.yaml`：只做收口，**故意不写 custom_styles**
  （DSL 的 hanging_indent_chars 是字符单位，会把英寸缩进覆盖掉）。
- `config/templates.json` 注册 `apa7`（lua_filter 直接用 apa7-style.lua，
  three_line_tables=false，绕开中文样式映射与三线表）。

**三个坑（详见 skill `apa7-english-paper-wordeditor`）**

1. 第一段管道 `--standalone` 把 `<title>` 写成输入文件名，第二段管道里
   docx writer 会把它渲染成开头的 `Title` 段 → 标题页上方多一行文件名。
   修法：Lua `Meta()` 里清 title，且必须 `pandoc.Meta(keep)` 重建
   （Lua 的 Meta 是 userdata，`meta.title = nil` 不删键）。
2. styles.yaml 里写 custom_styles 会把 reference.docx 的英寸缩进改成字符缩进。
3. `.tools/pandoc-3.9.0.2-arm64/bin/` 是**空目录**（二进制被剥掉），本机无 brew。
   正解：清华 PyPI 装 `pypandoc_binary`（46 MB/s），把
   `site-packages/pypandoc/files/pandoc` 复制到 `.tools/pandoc-3.9-arm64/bin/pandoc`。
   GitHub 直连被沙箱代理拒（CONNECT 502），ghproxy.net 只有 0.03 MB/s，都别用。

（John / Robertson / Westbrook）——这篇发于 8 月 5 日"黑色星期一"**前一周**。
立论：文章方向对、**归因排序错**。CFTC 净空头 $8.61bn 只是受监管期货期权的切片，
BIS 事后测算日元套利规模约 ¥40 万亿（$250bn）且明说因数据缺口而偏低；
真正的机制是杠杆+保证金（VaR shock / 跨币种基差），不是 15bp 加息。
政策落点：IMF 的 Article IV 是**双边**审查，而被撬动的敞口在**表外掉期市场**且是多边的，
没有哪一国的磋商能看见它 → 全球金融安全网中间有洞。
