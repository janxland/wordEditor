# 摘要

本文以医疗经济风险预测为场景，对比 Logistic 回归、随机森林与梯度提升 3 种模型，
验证 wordEditor 的「标题归一 / LaTeX 公式 / 引用上标」三宏后处理闭环。

一、绪论

碳中和与医疗经济风险预测均属于跨学科研究领域。传统经验法难以刻画指标间复杂的非线性关系[1]，
近年来数据挖掘方法被广泛应用于医疗费用、保险风险等场景[2]。

1.1 研究背景

医保基金的支付压力日益增大。设单次诊疗费用为 \(y_{预测}\)，对应的回归损失为
\(L = \frac{1}{n}(y - y_{预测})^2\)；权重 $\omega$ 满足 \left| W \right| \leq 1。

1.1.1 数据来源

数据来源于某三甲医院 2020—2024 年门诊与住院电子病历，共 \(N\) 条记录。

1.1.1.1 字段说明

主要字段包括年龄、性别、主诊断 ICD-10、住院天数、总费用等 12 项。

1.2 研究方法

采用十折交叉验证比较模型 AUC、F1、KS 指标，并对乘号示例 \(W \times PD_s\) 做下标渲染验证。

二、实证分析

随机森林在测试集 AUC 达到 0.86，明显优于 Logistic 回归的 0.78[1]，与文献[2]结论一致。

2.1 模型对比

| 模型 | AUC | F1 |
|------|-----|----|
| Logistic | 0.78 | 0.71 |
| 随机森林 | 0.86 | 0.80 |
| 梯度提升 | 0.88 | 0.82 |

2.1.1 误差分析

误差主要来源于罕见诊断的小样本问题。

三、结论与展望

本文完成了 wordEditor 三宏后处理闭环的端到端验证。未来工作将引入更多医院多中心数据。
