# Markdown 写作约定

## 标题编号（导出时自动识别）

在 Markdown 中**保留你习惯的手写编号前缀**；导出后 `postprocess_document.py` 会：

1. 用正则识别标题级别  
2. **去掉** `一、`、`1.1` 等前缀（正文只保留标题文字）  
3. 套用 Word「标题 1/2/3/4」并挂接**多级列表编号**

| 你写的行首 | 识别为 | 去掉前缀后示例 |
|------------|--------|----------------|
| `一、绪论` | 标题 1 | 绪论 |
| `1.1 研究背景` | 标题 2 | 研究背景 |
| `1.1.1 双碳政策` | 标题 3 | 双碳政策 |
| `1.1.1.1 试点省份` | 标题 4 | 试点省份 |
| `1 引言` / `1. 引言` | 标题 1 | 引言 |

### 模板差异（`config/templates.json`）

| 模板 id | 显示编号 |
|---------|----------|
| `hutb-gongke` 工科 | **1** → 1.1 → 1.1.1 → **2** → 2.1 → 2.1.1（章为阿拉伯数字） |
| `hutb-guanke` 管科 | **一、** → 1.1 → 1.1.1 → **二、** → 2.1 → 2.1.1（章用中文 numId，小节用 body 列表阿拉伯 `%1.%2`） |

正文只保留标题文字（如「绪论」），编号由 reference.docx 内 **numId=2** 多级列表自动生成（`w:isLgl` 保证新章从 1.1 / 2.1 起，而非 2.4）。

```powershell
# 管科（默认，适合 一、二、三、）
python scripts/build.py -t hutb-guanke

# 工科（章编号为 1、2、3…）
python scripts/build.py -t hutb-gongke
```

## 公式

行内：`\(E=mc^2\)` 或 `$E=mc^2$`；独立公式：`$$...$$`。  
导出时保持 **HTML 管道**（默认）。

## 参考文献

```markdown
参考文献

<a id="Ref1"></a>[1] 作者. 题名. 期刊, 2024.
```

正文引用写 `[1]`、`[2]`。
