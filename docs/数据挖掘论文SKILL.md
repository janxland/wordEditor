# 数据挖掘论文写作规范（外部 AI 撰稿 Skill）

> 用途：你（外部模型）将为湖南工商大学 **工科 / 管科 / 数学建模** 模板（`hutb-gongke` / `hutb-guanke` / `hutb-math-modeling`）撰写 **数据挖掘 / 机器学习** 方向的 Markdown 论文。文件随后由 `scripts/build.py` 经 Pandoc + 后处理脚本（`postprocess_document.py` / `postprocess_styles.py`）导出为 DOCX。
> **输出必须严格满足本规范**，否则会出现"双标题""章号错乱""公式乱码""指标表错位"等问题。

---

## 0. 输出要求（最重要）

1. **只输出一份 Markdown**，不要寒暄、不要解释、不要列"我做了什么"。
2. UTF-8 / LF 换行。正文中文标点用全角，代码与公式内部用半角。
3. 文件骨架固定：YAML front-matter → 摘要段 → 关键词行 → 正文章节。
4. 全文 **禁用** HTML（`<div>`/`<span>`/`<br>`/`style="..."`）、Word 域代码、emoji。
5. 数值结果（准确率、F1、AUC 等）一律保留 **四位有效数字**，并与正文 / 表格保持一致。

## 1. 论文题目只能写一次（避免"多出一个一级标题"）

> 与数学建模 Skill 完全相同：YAML `title` 与 `# <题目>` 二选一。

Pandoc 会把 YAML 中的 `title:` 渲染为独立的 **Title 段落**（黑体居中加粗）。
如果你同时再写一个 `# <题目>` 作为一级标题，后处理会把它识别成"标题 1"，并自动加上多级编号（工科 `1`、管科/数模 `一、`），从而出现两个题目。

### 正确做法（**只用 YAML title，不要写题目 H1**）

```markdown
---
title: 基于随机森林模型的老年人动作识别与跌倒预警系统
---

摘要

<300–500 字摘要……>

关键词：关键词1、关键词2、关键词3、关键词4、关键词5

# 引言            ← 第一个 H1，被自动编号为 "1 引言" 或 "一、引言"

## 研究背景      ← "1.1 研究背景"

...
```

### 兜底做法（确实想保留 H1）

```markdown
---
---

# 基于随机森林模型的老年人动作识别与跌倒预警系统

摘要
...
```

> **二者只能取其一**。本规范默认推荐**第一种**。

## 4. 公式

### 行内公式

- 推荐：`$\mathrm{Accuracy} = \frac{TP+TN}{TP+TN+FP+FN}$`，也可：`\(...\)`

### 独立公式

```markdown
$$
\mathrm{Gini}(D) = 1 - \sum_{k=1}^{K} p_k^{2}
$$
```

### 数据挖掘常用公式速查（请用反斜杠命令）

- 信息熵：`H(D)=-\sum_{k=1}^{K} p_k \log_2 p_k`
- 信息增益：`\mathrm{Gain}(D,A)=H(D)-\sum_{v}\frac{|D_v|}{|D|}H(D_v)`
- 交叉熵损失：`\mathcal{L}=-\frac{1}{N}\sum_{i=1}^{N}\sum_{k=1}^{K}y_{ik}\log\hat{y}_{ik}`
- 精确率/召回率：`P=\frac{TP}{TP+FP},\quad R=\frac{TP}{TP+FN}`
- F1：`F_1=\frac{2PR}{P+R}`
- AUC（积分形式）：`\mathrm{AUC}=\int_0^1 \mathrm{TPR}(\mathrm{FPR}^{-1}(t))\,\mathrm{d}t`

### 禁止事项

- 公式内 **禁混中文**（中文写在 `$…$` 外）。
- 命令必须带反斜杠：`\frac{a}{b}` ✅；`fracab` ❌。
- 矩阵用 `bmatrix`、分段函数用 `cases`、多行用 `aligned`。
- 希腊字母用命令：`\alpha \beta \gamma \theta`，不要直接打 `α β γ`。
- 算法术语用 `\mathrm{}`：`\mathrm{ReLU}`、`\mathrm{softmax}`，避免被斜体化。

# 相关理论与方法

## 随机森林

随机森林通过 Bootstrap 采样与随机特征子集训练多棵决策树，分类决策由多数投票给出，其经验风险可表示为

$$
\hat{f}(x) = \mathrm{argmax}_{k} \sum_{m=1}^{M} \mathbb{I}\bigl(h_m(x)=k\bigr)
$$

其中 $M$ 为树数量、$h_m$ 为第 $m$ 棵树。

## 评价指标

$$
\mathrm{F}_1 = \frac{2PR}{P+R},\quad
\mathrm{AUC} = \int_0^1 \mathrm{TPR}(\mathrm{FPR}^{-1}(t))\,\mathrm{d}t
$$
