# 数据挖掘论文写作规范（外部 AI 撰稿 Skill）

> 用途：你（外部模型）将为湖南工商大学 **工科 / 管科 / 数学建模** 模板（`hutb-gongke` / `hutb-guanke` / `hutb-math-modeling`）撰写 **数据挖掘 / 机器学习** 方向的 Markdown 论文。文件随后由 `scripts/build.py` 经 Pandoc + 后处理脚本导出为 DOCX。
> **输出必须严格满足本规范**，否则会出现"双标题""章号错乱""公式乱码""指标表错位"等问题。

---

## 0. 输出要求（最重要）

1. **只输出一份 Markdown**，不要寒暄、不要解释、不要列"我做了什么"。
2. UTF-8 / LF 换行；正文中文标点全角，代码与公式内部半角；中文与 `$…$` 之间不加空格。
3. 全文 **禁用** HTML（`<div>`/`<span>`/`<br>`/`style="..."`）、Word 域代码、emoji、`**加粗**` 充当标题、`> 引用` 充当正文。
4. 第三人称客观陈述；禁"我""我们""笔者"。
5. 分类 / 回归指标（Accuracy、F1、AUC、MAE 等）保留 **四位有效数字**，正文、表格、摘要保持一致。

---

## 1. 论文题目只能写一次

Pandoc 会把 YAML `title:` 渲染为独立 **Title 段落**（居中加粗）。若再写 `# <题目>`，后处理会叠加章号，出现两个题目。

**推荐（默认）**：只用 YAML，第一个 `#` 从 `# 引言` 起。

```markdown
---
title: 基于随机森林模型的老年人动作识别与跌倒预警系统
---

摘要
…
关键词：…

# 引言            ← 第一个 H1
## 研究背景
```

**兜底**：保留 H1 时 YAML 留空（`---` / `---`），**二者只能取其一**。

## 3. 标题规则

| Markdown | 样式 | `hutb-gongke` | `hutb-math-modeling` |
|----------|------|---------------|----------------------|
| `# 引言` | 标题 1 | `1 引言` | `一、引言` |
| `## 研究背景` | 标题 2 | `1.1 研究背景` | `1.1 研究背景` |
| `### 子节` | 标题 3 | `1.1.1 子节` | `1.1.1 子节` |
| `#### 更细` | 标题 4 | `1.1.1.1` | `1.1.1.1` |

**不要**手写 `1`、`1.1`、`一、`——会被叠加成 `1 1 引言`。统一用 `#`～`####`。

## 4. 公式

**行内**：`$\mathrm{Accuracy}=\frac{TP+TN}{TP+TN+FP+FN}$` 或 `\(...\)`

**独立**：

```markdown
$$
\mathrm{Gini}(D) = 1 - \sum_{k=1}^{K} p_k^{2}
$$
```

**常用**（命令须带反斜杠）：信息熵、信息增益、交叉熵、P/R/F1、AUC 等；矩阵用 `bmatrix`，分段用 `cases`，多行用 `aligned`；希腊字母用 `\alpha` 等命令；算法名用 `\mathrm{ReLU}`。

**禁止**：公式内混中文；`fracab` 这类无反斜杠写法。

## 7. 列表与代码

**列表**：无序 `- `；有序 `1. 2. 3.`（禁 `1)`、`①`）；同列表项间不留空行；列表内不放 `#` 标题。

**代码**：三反引号 + 语言；正文片段 ≤ 30 行，完整代码放附录；固定 `random_state`；禁缩进式代码块。

---

## 8. 参考文献

正文引用：`…Random Forest 仍具优势 [1]，深度模型在时序上更有竞争力 [2,3]…`

```markdown
# 参考文献

<a id="Ref1"></a>[1] Breiman L. Random Forests[J]. Machine Learning, 2001, 45(1): 5-32.
<a id="Ref2"></a>[2] Chen T, Guestrin C. XGBoost…[C]//KDD. 2016: 785-794.
```

- 每条前缀 `<a id="RefN"></a>`（后处理生成 REF 书签 + 上标链接）。
- 类型：`[J]` 期刊、`[M]` 专著、`[D]` 学位论文、`[C]` 会议、`[R]` 报告、`[EB/OL]` 电子。
- 编号与正文 `[N]` 一一对应、连续递增。**数量与构成要求见 §10**。

## 9. 数据挖掘内容要求（唯一内容清单）

写作时**必须覆盖**以下项（格式细节见 §3–§8，不再重复）：

| 模块 | 必须包含 |
|------|----------|
| **摘要** | 300–500 字：背景 → 数据规模 → 特征 + 模型 → **最优指标数值** → 应用价值 |
| **数据集** | 来源（公开集名 + URL / 自采流程）；总样本数及 train/val/test 比例与样本数；特征类型与缺失率；类别分布（不均衡给比例） |
| **预处理** | 缺失值、异常值、归一化/标准化、类别编码；是否重采样（SMOTE 等） |
| **特征工程** | 构造逻辑（含业务理由）；选择方法（过滤/包裹/嵌入式）；最终特征数 |
| **模型** | 选型理由；超参数搜索空间与最优值；训练硬件与时长 |
| **评估** | ≥3 种指标（分类 Accuracy/P/R/F1/AUC；回归 MAE/RMSE/R²；聚类轮廓系数/NMI）；≥3 个基线（含 ≥1 传统 + ≥1 集成）；**混淆矩阵或 ROC 图**；有重复实验时给显著性/置信区间 |
| **分析** | 消融或敏感性实验；可解释性（特征重要性 / SHAP / LIME 任选其一） |
| **结论** | 可量化最终成绩 + 局限 + 未来工作 |
| **参考文献** | **≥15 条**；经典算法原文 ≥2；近 3 年同主题 ≥3；近 5 年期刊 ≥5；英文 ≥3 |
| **附录** | 完整可运行代码、库版本清单、关键中间数据样例 |

**建议配图**（至少覆盖流程/架构、特征分布或热力图、学习/损失曲线、混淆矩阵或 ROC/PR、特征重要性中的 **3 类以上**）：

流程架构 · 特征分布/相关性 · 学习曲线 · 混淆矩阵 · ROC/PR · 特征重要性

**建议配表**：数据集统计 · 超参数搜索空间 · 模型对比（五指标） · 消融实验

## 11. 最小可用样例

```markdown
---
title: 基于随机森林模型的老年人动作识别与跌倒预警系统
---

摘要

针对老龄化背景下独居老人跌倒事件频发的现实问题，本文基于可穿戴式三轴加速度与陀螺仪传感器采集的 12 类日常动作数据（共 18,372 条样本，6 名受试者），构建了 32 维时频域特征向量，并对比 Logistic Regression、SVM、Random Forest、XGBoost 与 1D-CNN 五种模型。实验结果表明 Random Forest 在测试集上取得最优表现：准确率 0.9342、F1 值 0.9337、AUC 0.9712，跌倒事件召回率 0.9612。基于该模型搭建的实时预警原型系统平均推理延时 18.3 ms，能够在跌倒发生后 1.5 秒内触发告警，可为养老监护场景提供有效技术支撑。

关键词：跌倒检测、随机森林、可穿戴传感器、特征工程、机器学习

# 引言

## 研究背景
…

## 本文主要工作

1. 构建 32 维时频域特征体系。
2. 系统对比五类模型，验证 Random Forest 的有效性。
3. 实现端到端的实时跌倒预警原型。

# 相关理论与方法

## 随机森林

$$
\hat{f}(x) = \mathrm{argmax}_{k} \sum_{m=1}^{M} \mathbb{I}\bigl(h_m(x)=k\bigr)
$$

其中 $M$ 为树数量、$h_m$ 为第 $m$ 棵树。
```
