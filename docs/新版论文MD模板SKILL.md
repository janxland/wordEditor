# 中文论文 Markdown 写作与交付规范

本文件是给外部模型使用的写作提示词。模型应直接产出可交付的 Markdown 或按用户指定修改文件，不输出寒暄、过程说明、修改摘要或额外解释。除非用户明确要求，不改变论文研究主题、原始数据、图表含义和已核实的事实。

## 交付目标

输出必须是 UTF-8 编码、LF 换行的单一 Markdown 文件，能够被 Pandoc 及项目后处理脚本正常转换为 DOCX。正文使用自然、客观、专业的中文，避免可识别的套话、机械重复和模板化段落。不能承诺任何查重或检测工具的固定结果；写作目标是基于真实材料独立组织论证，减少套话和拼接式表达。除参考文献部分按项目要求保留的 `<a id="RefN"></a>` 锚点外，正文不使用 HTML。

论文题目只在 YAML front matter 中出现一次。默认采用下面的结构，题目之后直接进入摘要，不再添加同名 H1：

```markdown
---
title: 论文题目
---

摘要段落。

关键词：关键词1、关键词2、关键词3、关键词4、关键词5

# 引言
```

YAML 的两个 `---` 仅用于 front matter，不属于正文水平分隔线。正文任何位置都不得使用 `---` 作为水平分隔线。摘要是普通段落，不写 `# 摘要`；关键词单独成段。第一个 H1 应是“引言”或与论文结构对应的第一个章节，而不是论文题目。

## 标题和章节编号

Markdown 标题只写层级和标题文字，不写任何手工章号、节号或中文序号。使用 `#`、`##`、`###`、`####` 表示标题层级，由 reference.docx 和后处理脚本自动生成章节编号。

正确写法是 `# 引言`、`## 研究背景`、`### 样本特征`。禁止写成 `# 一、引言`、`## 1.1研究背景`、`## 1.1 研究背景`。不要用加粗文字、列表项或普通段落冒充标题。正文最多使用四级标题，标题层级应连续，不能从 H1 直接跳到 H3。

## 论文内容和篇幅

调查研究或实证论文应围绕研究问题、理论依据、研究设计、数据分析、地方情境、讨论和结论展开。可按实际主题采用“引言—理论与文献—研究设计—结果分析—讨论—结论与展望—参考文献—附录”的结构，不强行填充与研究无关的章节。

正文有效汉字数控制在约9000字，建议范围为8800至9200字。必须在交付前用代码统计，不凭肉眼估计。统计时明确口径：排除 YAML、参考文献、附录、代码和 Markdown 标记，统计摘要及正文中的中文汉字；表格中的文字是否计入应保持同一口径并在检查记录中说明。篇幅不足时补充事实依据、变量解释、结果解读和局限边界，不得重复句子、堆砌同义词或捏造数字；篇幅过长时优先删除重复论证和空泛背景。

统计可以使用如下 Python 逻辑，实际执行时应读取最终文件并报告计数结果：

```python
import re
from pathlib import Path

text = Path("paper.md").read_text(encoding="utf-8-sig")
text = re.sub(r"\A---\n.*?\n---\n", "", text, flags=re.S)
text = re.split(r"^# 参考文献\s*$", text, flags=re.M)[0]
text = re.split(r"^# 附录\s*$", text, flags=re.M)[0]
text = re.sub(r"```.*?```", "", text, flags=re.S)
count = len(re.findall(r"[\u3400-\u4dbf\u4e00-\u9fff\uf900-\ufaff]", text))
print(count)
```

摘要应概括研究背景、研究对象、数据来源、方法、主要发现和结论边界。摘要不写无法由正文或数据支持的精确效果，不使用空泛的“具有重要意义”等套话。关键词通常为3至5个，关键词之间使用中文顿号或逗号。

## 调查问卷和数据真实性

凡使用问卷或 Excel 数据，必须在“数据来源”“研究设计”或同等章节中交代问卷来源、设计依据、发布或回收渠道、调查时间、调查地域、调查对象、样本数量、有效问卷判定标准、匿名与知情说明以及数据清洗规则。不能只写“通过网络发放问卷”或“随机抽取了若干人”而不提供可核验的范围和过程。

如果研究在怀化市完成，应将怀化市作为真实研究情境写入研究设计和结果解释。可以讨论当地城乡结构、居民收入与就业构成、金融网点和数字金融可达性、旅游与服务业就业、老龄化、县域差异等因素，但每一项都必须有可靠的地方统计公报、统计年鉴、政府部门资料或可核验的调查题项支撑。不得为了加入地方因素凭空补充比例、收入、人口、网点数量或行为结论；无法核验的地方背景应删除或改写为研究边界。

处理已有 Excel 时，先读取工作簿、工作表、字段名、记录数和原始值，再决定是否清洗。用户要求保留200条记录时，必须核对最终数据确实有200条有效记录，不能通过复制、重排、随机改写、补齐或删除记录制造分布。保留原始文件或原始值的可追溯副本，清洗操作应能说明字段、规则和变化。

数据审计至少检查记录重复、缺失值、异常值、选项越界、逻辑矛盾、跳题关系、总数与分项之和、比例与频数对应关系，以及问卷选项和论文表格是否一致。发现来源、回收凭证、时间戳、地域标签或样本过程不足时，不得把数据表述为已核验的随机抽样或代表总体的真实调查。应准确交代数据能够支持的范围、样本局限和推断边界，不用虚构的调查过程补足缺口。

论文中的所有频数、百分比、均值、标准差、回归系数和显著性结果都必须由实际数据或可复核计算得到。图表、正文、摘要和结论中的同一指标必须一致；百分比应注明分母，四舍五入规则应统一。不要为了让结果更“真实”、更平滑或更符合预期而手工改动答案。

## 怀化市情境写作

怀化因素应服务于研究问题，而不是作为地名装饰。写作时说明样本是在怀化市收集或研究完成的事实，再将地方经济结构、城乡差异、居民金融经验、线下金融服务与移动互联网使用条件等因素与问卷变量建立可解释的联系。只有在问卷确实包含相应题项、分组或交叉分析时，才能把该因素写成调查发现；只有在有外部权威资料时，才能把它写成宏观背景。

地方数据引用应注明发布机构、资料名称、年份、发布日期或访问日期及链接。地方背景数据与问卷样本数据不得混为一谈，不能用怀化市总体统计数据替代问卷受访者特征，也不能把样本结果外推为怀化市全体居民结论。

## 降低模板化表达的写作要求

正文使用连续的自然散文段落。除符号说明、数据表、参考文献、代码和确有必要的附录外，不用项目符号或编号列表充当论证正文。一个观点应通过完整段落展开，段首直接陈述事实、判断或分析对象，不使用加粗词条加冒号的“伪小标题”。

禁止使用下列机械列举式表达及其连续变体：

- “第一，……；第二，……；第三，……”
- “一是……；二是……；三是……”
- “首先……；其次……；再次……”
- “排名第一……排名第二……排名第三……”
- “具体从以下维度展开分析：”
- “主要体现在以下几个方面：”
- “具有以下经济学特殊性：”
- “遵循以下原则：”

改用与事实相连的自然过渡，例如“在样本结构方面……”“从收入稳定性看……”“这一结果与……有关”。禁止用堆叠形容词、泛化结论、无来源的“显著提升”“全面促进”制造论文感。每个结论都应说明证据来源、适用范围和可能的替代解释。

第三人称客观表述，避免“我”“我们”“笔者”等主观叙述。中文正文使用规范全角标点，代码、路径和 LaTeX 公式内部使用半角字符。数字与中文单位、百分号、日期单位之间不得有空格，例如写“200条”“2024年”“56岁”“18.5%”，不写“200 条”“2024 年”“56 岁”“18.5 %”。全篇应扫描数字后的空格，包括表格、图注、参考文献、DOI、页码和附录说明。

最终交付的论文中不得出现“查重率为0”或其他无法验证的检测承诺，也不得出现图片生成或软件界面自动附带的无关文字，包括“图形用户界面”“应用程序”“AI 生成的内容可能不正确”等提示。不得把这些文字当作图题、图注或正文内容保留。

## 图片

图片使用相对路径，路径和文件名优先使用小写 ASCII，例如 `images/fig01.png`。每张图单独占一行，只保留一条 Markdown 图片语法：

```markdown
![互联网理财服务满意度分布](images/fig01.png)
```

alt 文本必须是准确、专业、能说明图中对象和指标的图注，例如“互联网理财服务满意度分布”“不同年龄组的理财产品选择比例”。alt 中不要手写“图1”“图4”或其他编号；不要在图片下方另写“图1……”或“图4……”重复题注，程序会自动生成图号。不要加粗图注，不要写宽度属性，不要并排图片，不要使用 HTML 图片标签。正文必须在图片前后用自然段引用和解释图片，不能只插图不分析。

图片文件必须真实存在，链接相对于 Markdown 文件所在目录可解析。图中数字应与数据表和正文一致，坐标轴、单位、样本量和统计口径要清楚。若图片由数据生成，保留生成数据和脚本的可追溯关系；若图片来自外部资料，应注明来源并确认使用权限。

## 表格

表题在表格上方，独立成行，不加粗、不加 `#`、不手写与程序编号冲突的章节号或表号。表格使用 GFM 管道语法，数值列右对齐，单元格内不使用 HTML、`<br>` 或嵌套表格：

```markdown
互联网理财产品选择情况

| 产品类别 | 选择人数 | 占比 |
| --- | ---: | ---: |
| 银行理财 | 72 | 36.0% |
```

表题和表格之间保留一个空行。正文必须引用并解释每张表，表内合计、百分比和小数位数必须经过代码复核。没有数据支持时不填入看似精确的数字。

## 公式和代码

行内公式使用 `$...$` 或 `\(...\)`，独立公式使用 `$$...$$`。LaTeX 命令必须带反斜杠，矩阵使用 `bmatrix`，多行公式使用 `aligned`，分段函数使用 `cases`，希腊字母使用 `\alpha`、`\beta` 等命令。公式内部不混入中文，不在中文和公式标记之间添加多余空格。

代码块使用带语言标识的三个反引号。正文只放必要的短代码，完整可运行代码放在附录；代码中的随机过程必须固定随机种子，注明运行环境、主要依赖版本和输入输出。不要使用缩进式代码块。正文不展示与结论无关的调试输出。

若论文属于数学建模或定量优化研究，需根据实际题目说明变量、参数、单位、目标函数、约束条件、求解算法、关键参数、结果验证、敏感性分析或误差分析。模型假设必须来自题目或数据条件，并解释适用边界，不能为了满足数量要求机械罗列假设。符号说明表应覆盖正文和公式中实际使用且出现次数达到约定阈值的符号。

## 参考文献和联网核验

正文引用采用连续编号，如“相关研究表明……[1]”或“已有方法存在差异[2,3]”。每个正文引用号必须对应一条参考文献，每条参考文献都必须在正文实际被引用；编号连续递增，不得出现未引用、重复编号或正文编号越界。

参考文献逐条独占一段，不使用项目符号。按项目后处理要求保留 `<a id="RefN"></a>` 前缀，例如：

```markdown
# 参考文献

<a id="Ref1"></a>[1] Breiman L. Random Forests[J]. Machine Learning, 2001, 45(1): 5-32. DOI:10.1023/A:1010933404324.
<a id="Ref2"></a>[2] 国家统计局. 中国统计年鉴2024[R]. 北京:中国统计出版社,2024.
```

每条文献在交付前必须联网核验。期刊论文至少核对作者姓名、题名、期刊名、年份、卷期、页码、DOI或正式链接；专著核对作者、书名、出版社和年份；学位论文核对作者、题名、授予单位和年份；政府报告或网页核对发布机构、标题、日期和稳定链接。优先使用期刊官网、出版社、Crossref、CNKI、万方、国家图书馆、政府官网等权威来源。不能仅凭搜索结果摘要、聚合网站或模型记忆确认文献。

作者名、题名、刊名、DOI、卷期页码和链接任何一项无法核验时，不得保留该条或把它写成已证实文献。应替换为主题相近且能够核验的真实文献。不得编造作者、拼接题名、杜撰 DOI、把网页转载物写成期刊论文。联网不可用时应明确停止在可核验范围内，不以猜测补全书目信息。

调查研究通常应同时引用经典理论、近年相关研究、统计公报或监管文件；文献数量和年份分布服从用户或学校要求，不为凑数添加无关文献。参考文献中的数字也遵守全篇无数字空格规则。

## 文件骨架

按研究内容调整章节，但可参考以下骨架。骨架中的标题不代表必须全部保留：

```markdown
---
title: 论文题目
---

摘要段落。

关键词：关键词1、关键词2、关键词3、关键词4、关键词5

# 引言
## 研究背景
## 研究意义
## 国内外研究现状
## 研究问题与文章结构

# 理论基础与文献综述

# 研究设计
## 问卷来源与调查群体
## 变量与指标
## 数据处理方法

# 结果分析
## 样本特征
## 描述性统计
## 交叉分析或模型结果

# 怀化市情境下的讨论

# 结论与建议
## 研究结论
## 研究局限
## 后续研究

# 参考文献

# 附录
```

如果是数学建模论文，可将“研究设计”和“结果分析”替换为问题重述、模型假设、符号说明、模型建立、模型求解、结果分析、模型评价与推广，但仍须遵守标题、图表、文献、数据真实性和自然段规则。

## 交付前自检

完成写作后必须执行检查，并只交付通过检查的最终 Markdown：

- 检查 UTF-8 编码和 LF 换行，确认文件可被 Pandoc 解析。
- 检查 YAML `title` 存在且题目未在正文重复；摘要不是 H1；正文没有水平分隔线。
- 扫描所有标题，确认没有手写“一、”“1.”“1.1”等编号，且层级连续。
- 用代码统计正文有效汉字数，结果应约9000字，并记录实际计数口径。
- 扫描数字与“年、月、日、岁、人、条、份、元、万元、%、‰”等单位之间的空格，也检查表格、图注和参考文献。
- 检查正文没有列举式套话、列表充当论证段落、加粗词条冒号式伪标题和主观第一人称。
- 检查每张图的文件存在、路径可解析、alt 是专业图注、无手写图号、无重复题注、无自动生成警告文字，并且正文有引用。
- 检查每张表有独立表题、表题在表格上方且不加粗，表格为 GFM 格式，数值和正文一致。
- 对问卷或 Excel 做记录数、重复、缺失、异常、逻辑一致性和频数比例复核；200条记录的要求必须由代码验证。
- 核对调查问卷来源、调查群体、调查时间、调查区域、有效样本标准和怀化市情境说明均有依据；不得将来源不明的数据写成代表性随机调查。
- 对每一条参考文献核验作者、题名、出版物、年份、卷期页码、DOI或链接；检查正文引用与 `<a id="RefN"></a>` 编号一一对应。
- 扫描除参考文献 `<a id="RefN"></a>` 锚点外的 HTML、Word 域代码、emoji、图片自动提示语和其他非论文内容。

检查发现事实、数据或文献无法核验时，应修改为有证据支持的表述、删除不可靠内容或补充真实来源，不能用新的数字或书目信息掩盖问题。
